# spb-map-tiles

Vector map tiles (z0–14), styles, sprites and fonts for St Petersburg and near
suburbs, mirrored from [OpenFreeMap](https://openfreemap.org) and served with
GitHub Pages. Generated automatically; do not edit by hand.

- Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, ODbL.
- Tiles © [OpenMapTiles](https://www.openmaptiles.org/), styles and hosting
  schema by [OpenFreeMap](https://openfreemap.org).
